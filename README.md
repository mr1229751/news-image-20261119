"The World Daily Briefing" is a one-page newspaper that sums up the world's news of Thursday 19 November 2026 in a single 1024x1024 image: a broadsheet front page carrying 42 verified stories from six continents — the Trump–Xi–Putin summit in China, Anthropic's record $81.3bn IPO and the GTA VI launch as the three lead packages, six supporting modules (Jeffries, Gaza, the Crimea bridge, Eisenkot, the EU's €45bn Ukraine loan, Cyclone Akvan), a by-the-numbers strip, and a dot-matrix world map with nine numbered pins beside 33 further dispatches. The design source is page.html; main.py is the entrypoint and simply copies the bundled entry.png into the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
